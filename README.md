# 15-turns-to-nuke
быстрая тетрадная пошаговая стратегия на двух координатных сетках, выросшая из школьного морского боя. Игроки строят базы, двигают юнитов, ведут разведку, тратят деньги и ОД, запускают ядерку на 15-й ход и пытаются не спалиться перед главным боссом — училкой.
