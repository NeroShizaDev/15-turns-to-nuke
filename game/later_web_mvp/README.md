# Later Web MVP

Цифровой MVP «Клеточной войны» на React + Tailwind CSS + Zustand. Цель — быстро проверить hotseat-версию с двумя полями, туманом войны, призраками старой разведки, боем и передачей управления между игроками.

## Команды

```bash
npm install
npm run dev
npm run build
```

## Что уже есть

- Две сетки 10×10: «твоя карта» и «карта противника».
- Zustand-store с состоянием хода, активного игрока, деньгами, ОД, логом, ядерным таймером и клетками.
- Структура клетки с `content`, `p1View` и `p2View`, чтобы хранить реальность отдельно от того, что видит игрок.
- Умный клик: выбранный юнит идёт в пустую соседнюю клетку, атакует соседнего врага или запускает особое действие.
- Ближняя атака: юнит тратит AP и 1 ОД, уничтожает цель-юнит или снимает 1 HP со здания; уничтожение всех base/HQ сразу завершает партию.
- Ответный удар пехоты: если атаковать вражескую пехоту вблизи, атакующий тоже погибает.
- Разведчик честно открывает только соседние клетки, включая диверсантов, и тратит AP/ОД.
- Артиллерия стреляет на 4 клетки только по разведанным `unit`/`building` целям, не может стрелять после движения, тратит 2 ОД и получает cooldown, пропуская следующий свой ход.
- Деньги теперь можно тратить: магазин нанимает пехоту ($10), разведчика и артиллерию в пустые клетки рядом со своей базой или HQ.
- Найм защищён от спама и утечек тумана: не больше 2 юнитов за ход, подсветка учитывает владельца базы/HQ и только видимую пустоту; скрытое препятствие срывает покупку логом.
- Игрок 1 получает стартовое обслуживание баз сразу, чтобы Игрок 2 не получал экономическое преимущество первым `nextTurn`.
- Ракетная шахта заряжает ядерный таймер до 15 только пока шахта жива; после 15/15 ракета запускается в полёт, а не даёт мгновенную победу.
- Движение и найм проверяют соседство с вражескими диверсантами: скрытый шпион раскрывается, только если его разведали или к нему подошёл юнит.
- Инженер чинит соседнее своё повреждённое здание на 1 HP за $10, 1 ОД и AP, с защитой от повторного ремонта того же здания в этот ход.
- Диверсант крадёт $5 у врага, если стоит рядом с разведанной вражеской базой или HQ.
- Движение создаёт ghost-запись только если противник уже видел юнит в старой клетке; скрытые перемещения не протекают через призраков.
- Кнопка завершения хода показывает transition-экран «передай управление».
- Черновой тетрадный стиль: бумага, синие линии, красная полоса, рукописная военная эстетика.
