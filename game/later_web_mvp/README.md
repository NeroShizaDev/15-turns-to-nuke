# Later Web MVP

Цифровой MVP «Клеточной войны» на React + Tailwind CSS + Zustand. Цель — быстро проверить hotseat-версию с двумя полями, туманом войны, призраками старой разведки и передачей управления между игроками.

## Команды

```bash
npm install
npm run dev
npm run build
```

## Что уже есть

- Две сетки 10×10: «твоя карта» и «карта противника».
- Zustand-store с состоянием хода, активного игрока, деньгами, ОД, логом и клетками.
- Структура клетки с `content`, `p1View` и `p2View`, чтобы хранить реальность отдельно от того, что видит игрок.
- Выбор своей пехоты и подсветка соседних клеток для движения.
- Движение создаёт ghost-запись для противника: тип юнита и номер хода, когда он был замечен в старой клетке.
- Кнопка завершения хода показывает transition-экран «передай управление».
- Черновой тетрадный стиль: бумага, синие линии, красная полоса, рукописная военная эстетика.
