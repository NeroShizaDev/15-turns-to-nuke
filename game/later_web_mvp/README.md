# Later Web MVP

Черновой план будущей веб-версии.

## Минимальный MVP

- Две сетки 10×10.
- Размещение зданий и юнитов.
- Очки действия на ход.
- Разведка клеток.
- Простая атака по координате.
- Лог событий.
- Локальная игра на одном устройстве.

## После MVP

- Онлайн-дуэль.
- Скрытая информация без подсматривания.
- Редактор сценариев.
- Режим Teacher Boss как party mode.
