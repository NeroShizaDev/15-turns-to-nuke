# Later Web MVP

Цифровой MVP «Клеточной войны» на React + Tailwind CSS + Zustand. Цель - быстро проверить hotseat-версию с двумя полями, туманом войны, призраками старой разведки, боем, footprint-зданиями, физической ракетой и передачей управления между игроками.

## Команды

```bash
npm install
npm run dev
npm run build
```

## Что уже есть

- Две сетки 10x10: «твоя карта» и «карта противника».
- Zustand-store с состоянием хода, активного игрока, деньгами, ОД, логом, ядерным прогрессом, физическими ракетами и клетками.
- Структура клетки с `content`, `p1View` и `p2View`, чтобы хранить реальность отдельно от того, что видит игрок.
- Здания представлены footprint-сегментами: `buildingId`, `originId`, `segmentIndex`, `damaged`.
- Умный клик: выбранный юнит идет в пустую соседнюю клетку, атакует соседнего врага или запускает особое действие.
- Ближняя атака: юнит тратит AP и 1 ОД, уничтожает цель-юнит или повреждает сегмент здания.
- Ответный удар пехоты: если атаковать вражескую пехоту вблизи, атакующий тоже погибает.
- Разведчик честно открывает только соседние клетки и тратит AP/ОД.
- Артиллерия стреляет на 4 клетки по карте противника, может бить по `?` вслепую, тратит 2 ОД и получает cooldown, пропуская следующий свой ход.
- Артиллерия может повредить физическую ракету: попадание в `nose` уничтожает ее сразу, два поврежденных сегмента тоже уничтожают цель.
- Деньги можно тратить: магазин нанимает пехоту ($10), разведчика и артиллерию в пустые клетки рядом со своей базой или HQ.
- Найм защищен от спама: не больше 2 юнитов за ход, а подсветка найма учитывает владельца и состояние сегментов базы/HQ.
- Ракетная шахта заряжает ядерный прогресс до 15 только пока у игрока есть активный сегмент шахты.
- После 15/15 создается rocket entity `{ rocketId, owner, cells, launchedTurn, direction, status, damagedCells }`; победа наступает только когда ракета полностью выходит за край карты.
- Движение создает ghost-запись только если противник уже видел юнит в старой клетке; скрытые перемещения не протекают через призраков.
- Кнопка завершения хода показывает transition-экран «передай управление».
- Черновой тетрадный стиль: бумага, синие линии, красная полоса, рукописная военная эстетика.
