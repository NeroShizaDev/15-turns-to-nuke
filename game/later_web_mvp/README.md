# Later Web MVP

Цифровой MVP «Клеточной войны» на React + Tailwind CSS + Zustand: **морской бой против ИИ, но с базами и юнитами**. У каждого своё поле 10×10, стреляешь по координатам противника вслепую, хитпоинтов нет — одно попадание сносит одну клетку.

Документ баланса Web MVP: [`docs/balance_web_mvp.md`](../../docs/balance_web_mvp.md). Любые изменения численных параметров Web MVP нужно проводить вместе с обновлением документа баланса.

## Команды

```bash
npm install
npm run dev
npm run build
```

## Устройство

- `src/lib/gameData.js` — все числа: цены, радиусы, доход, хранилище, ракета.
- `src/lib/rules.js` — чистый движок правил. Каждое действие `(state, player, ...) → { ok, state, message }`; игрок и ИИ ходят через одни и те же функции.
- `src/lib/ai.js` — ИИ-противник. Смотрит на поле игрока только через `seen` (то, что разведал или обстрелял), без подглядывания.
- `src/store/useGameStore.js` — Zustand: режим (`ai` / `hotseat`), выбор юнита, клики по картам, пауза «ИИ ходит…».
- `src/components/` — тетрадные карты и клетки.
- `src/lib/sprites.js` + `src/assets/sprites/` — миниатюры, нарисованные ручкой (оригиналы в `assets/МОБЫ И ПОЛЕ`, у копий фон бумаги сделан прозрачным). Здания 2×2 и 2×1 режутся по клеткам.

## Что уже есть

- Два раздельных поля: `boards.p1` и `boards.p2`. Клетка хранит `content` (что реально стоит), `seen` (что о ней знает противник) и `shot` (след вражеского выстрела для владельца).
- Урон как в морском бое: попадание в здание сносит одну клетку (ГБ 2×2 — по 1/4), попадание в юнита убивает его. Ответ: «мимо», «попадание! снесено 2/4», «уничтожена полностью!».
- Ход как на скетче: у каждого юнита 1 ОД (шаг или действие), у каждого здания 1 заказ. Производство — из меню здания (клик по зданию), как в Dune и Generals.
- Юниты бьют по полю противника в радиусе от своей координаты: пехота 1, разведчик 3 (тихо), диверсант 1, артиллерия 4 (перезарядка 4 хода). Можно вслепую.
- ИИ: строит базу и армию, разведывает, добивает вокруг попаданий, остальное прочёсывает по шахматке, подводит бойцов так, чтобы цель попала в радиус, сбивает ракеты. Старую «пустоту» через 5 ходов считает снова неизвестной.
- Журнал без утечек: стройка, найм и разведка видны только автору, выстрелы и пуски ракет — обоим.
- Экономика «здания — это спайс» ([`docs/economy.md`](../../docs/economy.md)): доход и хранилище по уцелевшим клеткам, снесённые клетки становятся руинами `※`, Сборщик вывозит обломки, инженер восстанавливает клетки из руин и разбирает здания, диверсант крадёт из хранилищ.
- Ракетная шахта (только нижние 3 ряда, видна противнику вместе с таймером) копит 15 ходов, затем ракета 2×2 летит вверх по полю владельца; два попадания — сбита, вышла за край — победа.
- Режим «вдвоём за одним экраном» с экраном передачи хода.
