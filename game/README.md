# Game

Папка для будущей цифровой версии «Клеточной войны».

## План

1. Сначала стабилизировать бумажные правила в `docs/` и `prototypes/`.
2. Затем выделить формальную модель:
   - карта;
   - клетки;
   - здания;
   - юниты;
   - туман войны;
   - структура хода;
   - условия победы.
3. После этого собрать web MVP в `later_web_mvp/`.

## Почему пока пусто

Ранний код без проверенных правил быстро превратится в переписывание. Эта папка фиксирует место для будущего приложения, но ядро баланса сначала тестируется на бумаге.
