# Combat

## Базовый принцип

В Web MVP бой намеренно завязан на разведку: игрок не может атаковать то, что его штаб не подтвердил как цель. Это сохраняет ценность разведчика и не превращает артиллерию в угадайку по `?`.

## Ближняя атака

- Ближняя атака доступна только по соседней клетке.
- Цель должна быть разведана активным игроком как `unit` или `building`.
- Если соседняя клетка остаётся `unknown`, сначала нужен разведчик.
- Пехота при атаке по пехоте получает ответный удар: оба юнита погибают.

## Артиллерия

- Дальность: до 4 клеток по Манхэттену.
- Стоимость: 2 ОД и AP артиллерии.
- После выстрела артиллерия получает cooldown ровно на 4 своих хода.
- Артиллерия не может двигаться и стрелять в один ход: передислокация батареи тратит её огневую возможность.
- Нельзя стрелять по `unknown`, `empty` или `ghost`.
- Разрешены только подтверждённые цели в `p1View`/`p2View`: `unit`, `building` или физическая `rocket`.

## Победа через уничтожение баз

После успешного урона по зданию игра проверяет базы и HQ. Если у игрока не осталось ни одной клетки `base` или `hq`, соперник сразу побеждает. Здания повреждаются по сегментам, а не через единый HP-объект.

## Почему нет blind fire в Web MVP

Слепой огонь можно оставить бумажным вариантом, но в Web MVP он отключён по умолчанию: иначе игрок может дешёво проверять туман войны артиллерией и обесценивать разведчика.

## Ракета как цель

Ядерная ракета в Web MVP занимает 2×2 клетки. Артиллерия может стрелять по её разведанным физическим клеткам; попадания помечают или уничтожают именно выбранные клетки ракеты.
