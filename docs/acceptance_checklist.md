# Web MVP Acceptance Checklist

Канонический MVP: морской бой против ИИ, но с базами и юнитами.

- [x] Два раздельных поля 10×10: `boards.p1` и `boards.p2`; клетка хранит `content`, `seen` (знание противника) и `shot` (след вражеского выстрела).
- [x] Хитпоинтов нет: одно попадание сносит одну клетку здания, юнит в 1 клетку погибает с первого попадания.
- [x] ГБ 2×2 после одного попадания теряет 1/4, после двух — 1/2; журнал пишет «снесено N/4».
- [x] Юниты бьют по полю противника в радиусе от своей координаты; стрелять вслепую можно.
- [x] У каждого юнита 1 ОД за ход (шаг или действие), общего пула ОД нет; у каждого производящего здания 1 заказ за ход.
- [x] Производство из меню здания: ГБ строит здания вплотную к базе и выпускает инженеров, Казарма — бойцов, Склад — Сборщиков; юнит выходит к воротам и действует со следующего хода.
- [x] Здание рисуется целиком: все его клетки одинаковые, выбор подсвечивает всё здание.
- [x] Артиллерия: радиус 4, перезарядка 4 своих хода.
- [x] Разведчик тихо вскрывает клетку в радиусе 3; противник об этом не узнаёт.
- [x] Диверсант: кража до $15 из здания, после чего вор засвечен.
- [x] ИИ-противник ходит через те же функции правил и видит поле игрока только через `seen`.
- [x] Режим «вдвоём за одним экраном» сохраняется как запасной.
- [x] Ядерная ракета — физический объект 2×2, летит вверх по полю владельца, сбита двумя попаданиями.
- [x] Шахту можно ставить только в нижних 3 рядах; её клетки и таймер сразу видны противнику, без шахты таймер обнуляется.
- [x] Склад приходит с бесплатным Сборщиком.
- [x] Экономика «здания — это спайс»: доход и хранилище по уцелевшим клеткам, доход сверх лимита сгорает.
- [x] Снесённая клетка становится руинами с обломками и высыпавшимися деньгами; Сборщик вывозит, инженер восстанавливает клетку стоящего здания.
- [x] Численные значения синхронизированы в `docs/balance_web_mvp.md`.
