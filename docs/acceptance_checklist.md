# Web MVP Acceptance Checklist

Этот чеклист фиксирует канонический MVP без параллельных store-архитектур.

- [x] Используется одна модель поля: плоский массив клеток `grid`, где каждая клетка хранит реальность (`content`) и видимость (`p1View`/`p2View`).
- [x] Здания занимают footprint на этом же поле: `base` = 1 клетка, `barracks` = 2 клетки, `hq` = 2×2, `rocketSilo` = 2×2.
- [x] Казарма — основной производственный объект для найма юнитов.
- [x] В Web MVP есть пехота, разведчик, инженер, артиллерия и диверсант.
- [x] Артиллерия стреляет на 4 клетки только по разведанной цели.
- [x] Артиллерия получает cooldown ровно на 4 своих хода.
- [x] Действие диверсанта стоит 2 ОД/AP.
- [x] Ядерная ракета — физический объект 2×2 / 4 клетки, а не абстрактный таймер победы.
- [x] Ракета движется вверх/вниз на 1 клетку за ход владельца.
- [x] Ракета повреждается и уничтожается попаданиями по физическим клеткам.
- [x] Численные значения синхронизированы в `docs/balance_web_mvp.md`.
