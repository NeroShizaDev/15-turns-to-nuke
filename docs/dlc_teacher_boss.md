# DLC: Teacher Boss

## Легендарный режим

Главный босс — не ядерка. Главный босс — училка.

Этот режим добавляет внешнюю угрозу: игроки не только воюют друг с другом, но и стараются не привлечь внимание учителя к тетради с военными картами.

## Когда включать

- Для шуточных партий.
- Для школьного сеттинга.
- Для режима «хаос поверх стратегии».
- Для тестов на скорость: чем дольше думаешь, тем выше риск проверки.

## Шкала подозрения

Ведите общий счётчик подозрения от 0 до 10.

| Событие | Подозрение |
| --- | ---: |
| Игрок слишком долго думает | +1 |
| Громко спорит о попадании | +1 |
| Рисует слишком большую ядерку | +1 |
| Переворачивает тетрадь в панике | +2 |
| Учитель проходит рядом | бросок события |

На 10 подозрения срабатывает проверка тетради.

## Проверка тетради

При проверке каждый игрок должен за 10 секунд закрыть или замаскировать военные записи. Если не успел — получает штраф сценария:

- пропуск следующего хода;
- потеря 5 денег;
- заморозка строительства ракеты на 1 ход;
- мгновенное поражение в хардкорном режиме.

## События училки

| d6 | Событие |
| ---: | --- |
| 1 | Учитель повернулся к доске — подозрение -1 |
| 2 | Учитель идёт между рядами — следующий шум даёт +2 |
| 3 | Вопрос по теме урока — ответь или пропусти действие |
| 4 | Проверка тетради у соседа — один ход без громких атак |
| 5 | Замечание классу — оба игрока теряют 1 ОД |
| 6 | Внезапная проверка — немедленно проходите проверку тетради |

## Принцип режима

DLC не должен ломать основную игру. Он добавляет давление, мемы и легенду, но базовые правила войны остаются прежними.
