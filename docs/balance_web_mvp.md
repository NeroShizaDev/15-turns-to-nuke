# Web MVP Balance

Этот документ фиксирует численные значения Web MVP. Если баланс меняется в коде, сначала обновляем эту таблицу, чтобы не менять правила «тихо».

## Поле и ход

| Параметр | Значение |
| --- | ---: |
| Размер поля | 10×10 клеток |
| Очки действия на ход | 6 ОД |
| Лимит найма | 2 юнита за ход |
| Стартовые деньги | $40 |
| Компенсация первого хода P1 | +доход за стартовые здания |

## Юниты

| Юнит | Стоимость | Действие |
| --- | ---: | --- |
| Пехота | $10 | ближняя атака по соседней разведанной цели, пехота отвечает взаимным уничтожением |
| Разведчик | $8 | разведка соседней клетки за 1 ОД/AP |
| Инженер | $15 | ремонт соседнего повреждённого сегмента здания за $10, 1 ОД/AP |
| Артиллерия | $20 | выстрел по разведанной цели на 4 клетки за 2 ОД/AP |
| Диверсант | $15 | кража $5 у разведанной соседней базы/HQ за 2 ОД/AP |

## Здания

| Здание | Размер | Доход | Роль |
| --- | ---: | ---: | --- |
| База | 1 клетка | +$5 | экономическая цель |
| Казарма | 2 клетки | $0 | основной источник найма юнитов |
| Главная база / HQ | 2×2 / 4 клетки | +$20 | ключевая база и цель диверсанта |
| Ракетная шахта | 2×2 / 4 клетки | $0 | заряжает ядерную ракету |

Здания не заменяются единым HP-объектом: каждый сегмент здания — отдельная клетка. Первый удар по сегменту ставит `damaged`, повторный удар по тому же сегменту уничтожает эту клетку.

| Blind fire | запрещён |

## Ядерная ракета

| Параметр | Значение |
| --- | ---: |
| Зарядка шахты | 15 своих обслуживаний шахты |
| Физический размер ракеты | 2×2 / 4 клетки |
| Скорость | 1 клетка за ход владельца |
| Направление P1 | вверх |
| Направление P2 | вниз |
| Победа | ракета доходит до края карты противника |
| Уничтожение | попадания по физическим клеткам ракеты |
