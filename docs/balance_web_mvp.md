# Web MVP balance

Документ фиксирует численные параметры Web MVP и служит обязательным changelog-спутником для будущих правок баланса.

## Источники параметров

Ожидаемые источники для аудита баланса:

- `game/later_web_mvp/src/lib/gameData.js`
- `game/later_web_mvp/src/store/useGameStore.js`

На текущей ветке `work` эти файлы отсутствуют, поэтому численные параметры из них не могут быть достоверно извлечены и зафиксированы в таблице ниже. Когда исходники Web MVP появятся в репозитории, этот раздел нужно обновить в том же изменении, где добавляются или меняются числа.

## Текущие численные параметры

## Правило изменения баланса

Любое будущее изменение численных параметров Web MVP должно проходить вместе с обновлением этого документа: значение, источник, краткое обоснование и закрываемый playtest-риск должны оставаться синхронизированными с кодом.
