# Rules v0.1

## Компоненты

- 2 карты 10×10 на каждого игрока: «твоя карта» и «карта противника».
- Ручка или карандаш.
- Общая таблица обозначений.
- Счётчики денег, ОД, зарядки артиллерии и прогресса запуска ракеты.

## Цель игры

Игрок побеждает, если выполняет одно из условий:

1. уничтожает все базы противника;
2. сбивает ядерную ракету противника;
3. заставляет противника остаться без базы и без юнитов;
4. успешно запускает ядерную ракету и доводит её до края карты противника.

Игрок проигрывает, если ракета противника достигает края его карты и не была сбита, либо если все его базы уничтожены.

## Подготовка

1. Каждый игрок тайно размещает здания на своей карте.
2. Рекомендуемый старт:
   - 1 главная база 2×2;
   - 1 обычная база 1×1;
   - 1 казарма 2×1;
   - 1 ракетная шахта 2×2;
   - 1 пехота;
   - 1 разведчик;
   - 1 инженер;
   - 1 артиллерия;
   - 1 диверсант.
3. На карте противника отмечаются только неизвестные клетки `?`, если они были разведаны частично.

## Ресурсы

- **Деньги:** приходят каждый ход с баз и тратятся на здания/юнитов.
- **ОД:** очки действия. На них оплачиваются движение, атаки, разведка и спецдействия.
- **Заряд:** некоторые атаки имеют перезарядку.

## Базовые ограничения

- В Web MVP артиллерия не стреляет по неизвестным `?`: клетку сначала нужно разведать. Для бумажного прототипа слепой огонь можно оставить отдельным опциональным режимом.
- Урон наносится по зданиям, ракетам и юнитам, которые действительно находятся в клетке в момент атаки; многоклеточные здания повреждаются по отдельным клеткам-сегментам, а не через общий HP-объект; если после атаки у игрока не осталось `base`/`hq`, он проигрывает.
- Юнит, ушедший из ранее разведанной клетки, не обязан оставлять точную информацию на карте противника.
- Казарма — основной производственный объект: Web MVP нанимает юнитов только рядом со своей живой неповреждённой казармой.
- Пока у игрока есть хотя бы 1 база и 1 юнит, он остаётся в игре.

## Рекомендуемые стартовые параметры

| Параметр | Значение |
| --- | --- |
| Размер карты | 10×10 |
| ОД за ход | 6 |
| Доход базы | +5 денег/ход |
| Доход главной базы | +20 денег/ход |
| Ракета заряжается в шахте | 15 своих обслуживаний |
| Размер физической ракеты | 2×2 / 4 клетки |
| Движение ракеты после запуска | 1 клетка вверх/вниз за ход владельца |
| Дальность артиллерии | 4 клетки |
| Cooldown артиллерии | 4 своих хода |
| Стоимость действия диверсанта | 2 ОД |
