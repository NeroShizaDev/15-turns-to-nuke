# Nuclear Rocket

## Назначение

Ядерная ракета - таймер партии, который после завершения строительства становится физической сущностью на сетке. Прогресс 15/15 сам по себе больше не означает мгновенную победу: он запускает ракету, которую еще можно сбить до выхода за край карты.

## Строительство

- Ракета строится в ракетной шахте.
- Базовое время строительства: 15 ходов.
- Шахта занимает 2x2 клетки.
- Если все активные сегменты шахты повреждены или уничтожены, прогресс можно заморозить до ремонта.

## Запуск

Когда `rocketProgress[player]` достигает `ROCKET_LAUNCH_TURNS`, игра создает rocket entity:

```js
{ rocketId, owner, cells: [ids], launchedTurn, direction, status, damagedCells }
```

Правила размещения:

1. Ракета стартует из клеток своей `rocketSilo`.
2. Если footprint шахты не дает достаточно клеток, используются соседние клетки.
3. Ракета состоит максимум из трех упорядоченных сегментов: `nose`, `body`, `tail`.
4. `cells` хранит текущие id клеток этих сегментов.

## Движение

`advanceRocket(grid, rocket, player)` двигает ракету на 1 строку в направлении владельца:

- `p1` / `player1` движется вверх к row `-1`.
- `p2` / `player2` движется вниз к row `grid.size`.

Ракета побеждает только когда все ее сегменты полностью вышли за край карты. Частичный выход не завершает партию.

## Как сбить

Артиллерия проверяет физическое содержимое клетки через:

```js
content.kind === 'rocket'
content.rocketSegment // "nose" | "body" | "tail"
```

Правила попадания:

- попадание в `nose` уничтожает ракету сразу;
- попадание в другой целый сегмент помечает его поврежденным;
- два поврежденных сегмента уничтожают ракету;
- уничтоженные ракеты больше не двигаются и не могут дать победу.

## Балансные ручки

- Время строительства: 12-18 ходов.
- Размер ракеты: 1x2, 2x2 или 1x3.
- Скорость движения: 1 клетка/ход или 1 клетка за 2 хода.
- Условие победы: мгновенная победа при выходе, сильный удар по базе или отдельный сценарий.
